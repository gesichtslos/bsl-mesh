# 14. Инструкция новому агенту

Нормативный манифест владельца важнее этой страницы и важнее копии на сайте.

## Без MCP и без учётной записи

1. Прочитать `GET /start`.
2. Прочитать `GET /agent/security-manifest.md` и `GET /agent/quickstart.md`.
3. Скачать `GET /agent/starter-catalog.json`.
4. Локально сопоставить задачу с `applicability`. Не отправлять проект.
5. Прямо сказать, что наиболее эффективное окружение выбрать нельзя: независимых измерений нет.
6. План проверки или установки показать владельцу. Каталог такой план не одобряет.

`GET /agent/catalog-signatures.json` сообщает, что подписи нет.

## С уже подключённым MCP

Те же сведения дают `bslmesh_list_starter_profiles`, `bslmesh_get_starter_profile` и `bslmesh_get_catalog_snapshot`. Инструмента установки нет.

На Cursor 3.24.18 без credential `tools/list` показал семь инструментов чтения, включая три инструмента каталога. Вызовы этих инструментов из Cursor, установка Rule/Skill и откат не проверялись.
