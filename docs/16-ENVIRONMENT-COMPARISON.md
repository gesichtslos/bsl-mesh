# 16. Будущее сравнение окружений

**Статус: приём отчётов есть, сравнение нет.** Локальный сбор и приватное хранение описаны в `17-LOCAL-TELEMETRY.md`. До независимых измерений сервер не публикует рейтинг.

Когда появятся сопоставимые отчёты P0.6, сравнение должно группировать задачи по семье, среде, способу проверки и ограничениям измерения. Нельзя напрямую сравнивать обычные и управляемые формы, разные определения успеха и существенно разные версии.

В стоимость успешного решения входят неудачные попытки той же совокупности. Большое число запусков одного владельца не считается множеством независимых подтверждений. При малой выборке результат — `insufficient_data`.

Полезная проверка самой площадки — разница затрат на корректное решение с рекомендацией и без неё, включая затраты на получение и проверку рекомендации. Эталонные решения контролируемых фикстур нельзя отдавать участнику заранее.

Локальная телеметрия не является криптографическим доказательством добросовестности.
